# 🪟 Active Directory Monitoring Projects

This repository provides beginner-friendly, hands-on projects to understand and practice Active Directory (AD) monitoring, logging, performance analysis, and alerting using industry-standard tools.

Active Directory is a critical component in enterprise environments, and effective monitoring is essential for detecting misconfigurations, performance issues, and security threats.

---

## 📂 Projects Included

### 1. Active Directory Monitoring with Grafana
This project focuses on visualizing Active Directory metrics using Grafana dashboards.

**Key Focus Areas:**
- Setting up Prometheus Data Source in Grafana  
- Creating a Dashboard for AD Metrics  
- Monitoring AD User Logon Events  
- Setting Up Alerts for AD Performance Issues
- Visualizing AD Security Events

---

### 2. Active Directory Logs and Insights with Splunk
Learn how to ingest and analyze Active Directory logs for security monitoring and incident detection.

**Key Focus Areas:**
- Configuring Data Inputs in Splunk  
- Creating a Dashboard for AD Logon Events  
- Analyzing AD Security Events  
- Setting Up Alerts for AD Anomalies  
- Generating Reports on AD Activity

---

### 3. Real-time Active Directory Metrics with Datadog

**Key Focus Areas:**
